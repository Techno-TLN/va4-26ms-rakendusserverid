## Harjutus 0 – SSH-võti GitHubi (kohe tunni alguses!)

Sama võti on hiljem ka sinu sissepääs kursuseserverisse: õpetaja võtab selle GitHubist automaatselt.

```bash
ssh-keygen -t ed25519 -C "eesnimi@tva4-26ms"     # Enter, Enter (parool soovi korral)
cat ~/.ssh/id_ed25519.pub                         # Windows: type $HOME\.ssh\id_ed25519.pub
```

1. GitHub → **Settings → SSH and GPG keys → New SSH key**, kleebi **.pub** faili sisu.
2. Kontrolli: `ssh -T git@github.com` → *Hi <kasutaja>! You've successfully authenticated…*
3. Kirjuta oma **GitHubi kasutajanimi** Teamsi vestlusse / õpetaja vormi.

📖 https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent

## Harjutus 1 – Repo ja leht

1. Loo GitHubis uus avalik repo `tva4-26ms-<eesnimi>`.
2. Klooni see arvutisse.
3. Kopeeri sinna selle repo kaust `naide/public/` → `public/`.
4. Muuda `public/index.html` failis nimi enda omaks, siis tee commit ja push `main`-i.

## Harjutus 2 – GitHub Pages Actionsiga

1. Kopeeri `naide/workflows/pages.yml` oma repos asukohta `.github/workflows/pages.yml`.
2. GitHubis vali **Settings → Pages → Source: GitHub Actions**.
3. Push. Vaata **Actions** vaadet ja ava leht aadressil `https://<kasutaja>.github.io/tva4-26ms-<eesnimi>/`.
4. **Pull Request:** tee haru `feature/pealkiri`, muuda pealkirja, push ja ava PR. Merge'i järel vaata, kuidas Actions käivitub ja leht muutub.

📖 https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Harjutus 3 – SSH kursuseserverisse

Õpetaja on sinu kasutaja loonud ja võtme GitHubist võtnud (kasutajanimi ja aadress on Teamsis tabelis):

```bash
ssh <kasutaja>@193.40.160.3.sslip.io
whoami; pwd; ls -la /var/www/<kasutaja>
tail -n 20 /var/log/nginx/access.log    # kas õigus on? kui ei, siis miks?
exit
```

Kui tuleb `Permission denied (publickey)`: kas võti on GitHubis (`https://github.com/<github-kasutaja>.keys`)? Kas kasutad sama arvutit, kus võtme lõid?

## Harjutus 4 – Käsitsi deploy

Kõik käsud käivita oma repo kaustas, **oma arvutis**:

```bash
rsync -avzn --delete --chmod=D755,F644 ./public/ <kasutaja>@193.40.160.3.sslip.io:/var/www/<kasutaja>/   # proov
rsync -avz  --delete --chmod=D755,F644 ./public/ <kasutaja>@193.40.160.3.sslip.io:/var/www/<kasutaja>/   # päriselt
```

Ava `http://<kasutaja>.193.40.160.3.sslip.io` ja kontrolli: `curl -I http://<kasutaja>.193.40.160.3.sslip.io`.

> **Windows:** rsync ei ole PowerShellis vaikimisi olemas. Kasuta WSL-i või asendusena `scp -r .\public\* <kasutaja>@193.40.160.3.sslip.io:/var/www/<kasutaja>/`
