**Eesmärk:** õpilane näeb, mis jääb ühises serveris õpetaja hooleks, ja teeb vähemalt ühe sammu ise. Lõpus esitleb ta oma deploy teekonda.

## Valikteemad

### A. Oma VPS

Telli VPS (Zone, Hetzner vms, Ubuntu 26.04 LTS) ja korda sellel ühise serveri seadistus [OPETAJALE.md](../OPETAJALE.md) järgi. Suuna deploy workflow ümber, vahetades ainult secret'id.

- Zone VPS: https://www.zone.ee/et/vps/
- Ubuntu Server alused: https://documentation.ubuntu.com/server/

### B. HTTPS

Kas oma serveris või õpetaja demona ühises serveris:

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d minudomeen.ee
sudo certbot renew --dry-run
```

Eeldused: domeeni A-kirje näitab serverile ja port 80 on avatud.

📖 https://certbot.eff.org/

### C. Docker

Paki `app/` konteinerisse ja ehita image Actionsis (GHCR):

```dockerfile
FROM node:24-alpine
WORKDIR /app
COPY server.js .
ENV PORT=3000
EXPOSE 3000
CMD ["node", "server.js"]
```

- Docker alused: https://docs.docker.com/get-started/
- Image GitHubi registrisse: https://docs.github.com/en/packages/managing-github-packages-using-github-actions-workflows/publishing-and-installing-a-package-with-github-actions

## Lõputöö nõuded

Õpilase repos on:

- [ ] `public/` staatiline leht, mis kasutab API-t
- [ ] `app/` REST API (vähemalt GET, POST, DELETE)
- [ ] CI workflow, mis kontrollib PR-i
- [ ] deploy workflow, mis paigaldab `main`-i serverisse ja teeb tervisekontrolli
- [ ] `main` on kaitstud (merge ainult PR-iga)
- [ ] README: mis rakendus teeb, deploy teekonna joonis, mis oli raske

Esitlusel teeb õpilane otse PR-i ja näitab, kuidas muudatus jõuab live'i.
